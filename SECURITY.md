# Security policy

## Supported versions

Fixes go into the latest release of the plugins on the `stable` branch.

## Reporting a vulnerability

Report it privately, not as a public issue: [report a vulnerability](https://github.com/CedarLoom/cedarloom/security/advisories/new) through GitHub private vulnerability reporting (the repository's Security tab). Include the plugin version, the command or page involved and the steps to reproduce.

## After a report

- You get a first answer within 14 days.
- A confirmed vulnerability is fixed in a release within 90 days of the report, and the disclosure date is agreed with you.
- The fix and the GitHub security advisory are published together.
