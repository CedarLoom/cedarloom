# Models

Each session and subagent runs on the model and effort of its task in the model map, passed in the call: `node <this skill's folder>/models.mjs <project path> --depth <depth> --risk <class>` prints each task's value and the row and file that set it, from [models.json](models.json), then the user file `~/.config/cedarloom/cedarloom.json` (or under `$XDG_CONFIG_HOME`), then the project's `cedarloom.json`. `<class>` is the `Risk:` class, `critical` for a change to authentication, permissions, secrets, input validation or firmware safety. A spec's Flow line or the user overrides a value.
