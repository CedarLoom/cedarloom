# Maintainer bot run

One maintenance pass over the default branch. [SOUL.md](SOUL.md) holds first; the prompt names `<maintain folder>`, the `maintain` skill folder of the installed cl-repo plugin, and the result file.

1. Clone as step 1 of [bot-worker.md](bot-worker.md) says, `maintain` for `<n>`, on the default branch.
2. Take the steps of `<maintain folder>/SKILL.md` there up to its Report: change, commit and push nothing.
3. Report in the result file, with the file tool: the findings, ranked as its Report says, each with a short title of your own; the commit read; the parts skipped and why. Delete the clone as step 6 of [bot-worker.md](bot-worker.md) says, and end.
