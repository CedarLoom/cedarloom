# Skills

A skill is a set of instructions the agent loads for one kind of work. The agent starts `workflow` on its own before the first edit. Every other skill waits until you type its command. In Codex you type `$` instead of `/`; `coordinate` runs only in Claude Code.

This list is built from each skill's own front matter, the same source as the [skills reference](/reference/skills), which also says when each skill runs and what it writes.
